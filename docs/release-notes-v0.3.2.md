# campus-auth v0.3.2

> 自动保护提速版：在线复核间隔从 300 秒缩短到 60 秒并可配置；新增 Windows 网络变化
> 监听，掉线/换网时立即复核重连；配置界面「高级设置」可调间隔。

## ⚡ 断线重连更快

### 在线复核间隔缩短（默认 60 秒，可配置）

- 旧版：在线时每 300 秒才复核一次，掉线后最坏约 **5 分钟**才发现
- 新版：默认每 **60 秒**复核一次（可在配置界面调整 5–3600 秒），最坏约 **1 分钟**发现
- 失败退避仍为 60/120/240/300 秒；退避上限同样可配置（5–3600 秒）

### 网络变化即时触发（Windows）

- 监听 Windows 本地地址表变化：网卡连上/断开、DHCP 换址、Wi-Fi 切换等
- 变化后防抖 2 秒（等 DHCP/网关就绪）立即复核，不必等下一个轮询周期
- 监听接口不可用时自动退化为普通轮询，不影响认证主流程
- 可在 `portal.json` 用 `"watch": {"network_events": false}` 关闭

## ⚙️ 配置方式

- 配置界面 → 高级设置 →「自动保护」分组：在线复核间隔（秒）、失败重试上限（秒）
- 或直接编辑 `portal.json`：

  ```json
  "watch": {
    "recheck_interval": 60,
    "max_interval": 300,
    "network_events": true
  }
  ```

- 修改后点「开始自动保护」（保护中会自动重启守护进程）即可生效
