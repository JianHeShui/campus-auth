# campus-auth v0.2.7

> 体验更新：托盘直观显示「保护中 / 未保护」；保护中再次开始会自动重启保护；「一键生成配置」会自动校验门户类型是否与所选一致。

## ✨ 新功能

### 托盘显示保护状态

- **悬浮提示**：鼠标移到托盘图标上，显示「校园网自动保护：保护中 / 未保护」，每 5 秒自动同步。
- **右键菜单**：首行显示「状态：保护中 / 未保护」；保护中时「开始保护」变为「重新开始保护」。
- 守护进程可能由配置界面 / 托盘 / 开机自启任一处启动或停止，托盘状态都会随之更新。

### 保护中再次开始 = 自动重启保护

- 配置界面点「开始自动保护」时，若当前已在保护中：**先停止旧守护进程，再重新启动**，新配置立即生效（不再提示"已在运行"）。
- 托盘菜单「重新开始保护」行为一致。
- 未处于保护时点击则正常开始，并提示「已开始保护」。

### 「一键生成配置」自动校验门户类型

点击「一键生成配置」后：

1. 立即按所选类型 + 地址生成配置；
2. 后台自动探测一次真实门户类型，并与所选类型对比：
   - **一致**：提示「自动探测确认门户类型一致」；
   - **不一致**：弹窗提醒「探测到的是 X，您选的是 Y」，并询问是否改用探测结果重新生成（选「是」立即切换）；
   - **自定义模板**：仅提示探测结果，不覆盖手填内容；
   - **无法识别**（已联网 / 地址不可达）：提示核对配置，不打扰。
3. 探测期间「自动探测类型」按钮显示「探测中…」，完成后显示耗时。

## 安装与使用

1. 解压 zip 到任意目录
2. 双击 `campus-auth.exe`
3. 首次启动：弹出配置界面 + 托盘 + 创建桌面快捷方式
4. 填门户地址（或断网点「自动获取」）→「一键生成配置」（自动校验类型）→「开始自动保护」
5. 勾选「开机自启」后，重启电脑自动以托盘运行

## 注意事项

- 无需安装 Python，独立运行
- 若杀毒软件提示，请添加信任
- 从旧版升级：解压覆盖 `_internal` 与 `campus-auth.exe`，**不要删除同目录下的 `portal.json`**
