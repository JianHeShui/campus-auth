# campus-auth v0.3.3

> 托盘退出体验优化：点击托盘「退出」时，已打开的配置界面窗口会一同关闭
> （并且走正常关闭流程，先自动保存配置再退出）。

## 🪟 托盘退出更干净

点击托盘右键菜单「退出」时，现在会依次：

1. **关闭正在打开的配置界面窗口**（发送 `WM_CLOSE`，让窗口走正常关闭流程，
   会先自动保存 `portal.json`，不是强杀进程）；
2. 停止自动保护守护进程；
3. 移除托盘图标并退出。

细节：

- 配置窗口标题由 `campus_auth.CONFIG_WINDOW_TITLE` 统一维护，配置界面创建窗口
  与托盘查找窗口共用同一个常量，避免标题不一致导致找不到；
- 配置窗口未打开时，退出流程不受影响（照常停止守护并退出）；
- 配置窗口收到关闭请求后会执行原有的「关闭前自动保存」逻辑，不会丢配置。
