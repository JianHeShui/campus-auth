# campus-auth v0.2.6

> 全面修补版：把此前诊断出的稳健性缺口、死代码与工程化欠账一次性补齐。功能行为与 v0.2.5 一致，重点是"更稳、更准、更好维护"。

## 🐛 稳健性修复

### 联网探测更准确（DNS 故障场景）

- `client._internet_ok` 改为**先做不依赖 DNS 的 IP 探针**（NCSI 检测点 IP + 内容校验），再做域名 TLS 探测；避免校园网 DNS 故障时把"已联网"误判为"未联网"。
- `network.internet_ok_by_ip` 不再只靠公网 IP 的 80 端口超时判断，优先访问 NCSI 检测点并校验正文（劫持页正文不匹配 → 判未联网），旧逻辑保留为回退。

### 网络层健壮性

- 网卡枚举：缓冲区不足时按 Windows 回传的大小自动扩容重试（网卡/虚拟网卡较多的机器不再枚举失败）。
- HTTPS 可达判定放宽为 2xx/3xx（有些站点对 HEAD 返回 405/重定向，旧逻辑会误判为不可达）。
- captive 探测支持 `https` 探测地址（此前硬编码 80 端口，https 探测 URL 会失败）。
- 业务成功判定兼容字符串形式的 `code`（`"200"`）。

### 门户类型探测

- 7 个特征请求改为**并发执行**：最坏耗时从 6×timeout 降到约 1×timeout，界面显示实际耗时。
- CAS 判定改为**校验响应正文确实是 JavaScript**（检查 Content-Type 与 JS/HTML 特征）；SPA 门户对任意路径返回 200 index.html 时不再被误判成华三 CAS。
- HTTPS 自签名门户：证书校验失败时自动用宽松模式重试一次（此前探测直接全失败）。

## 🖥️ 配置界面

- **输入校验**：端口必须是 1–65535 的数字；「通用登录」额外固定字段必须是合法 JSON 对象。非法输入会明确提示，不再静默写坏配置或按钮无反应。
- **关窗保存**：关闭窗口自动保存失败时会提示（此前静默吞掉，可能丢配置）。
- **窗口自适应**：初始尺寸按屏幕可用区计算，1366×768 等小屏不再超屏 / 底部按钮被裁。
- **探测进度**：探测期间按钮显示「探测中…」，结束后恢复并显示耗时。
- 删除未使用的 `SlimScrollbar`、`_blend` 与多余 Token 引用。

## 🪟 系统集成

- 桌面快捷方式：源码运行时图标改用 `tray.ico`（此前指向 pythonw.exe 图标）；含空格路径的参数正确加引号（安装到 `C:\Program Files\...` 也有效）。
- pip 安装场景：托盘图标回退到包内副本（`package-data` 声明），不再丢图标。
- `AGENTS.md` 等交接文档不随项目分发（仅本地）。

## 🧹 死代码与工程化

- 删除未使用的 `launcher.py`、`config_app.py`。
- `theme.py` 从"完整设计系统"精简为实际被引用的配色/间距 Token（删除未使用的自绘组件、字体体系、动效与兼容映射）。
- `client` 新增公共 `is_online()`，CLI 不再调用私有方法；删除空实现的 `_log`。
- 错误分类统一走画像 `error_markers`（去掉两处硬编码关键词）；服务名不在门户列表时写日志，便于排查运营商/计费问题。
- 新增 **`.github/workflows/tests.yml`**（Windows CI，Python 3.10 / 3.12，自动跑全部单测）。
- `build.ps1`：自动读取版本号、校验产物、并生成 `dist/campus-auth-v<版本>.zip`（散开结构，与历史发布包一致）。
- `pyproject.toml`：补充 `project.urls`、`package-data`、`ruff` 配置与 `dev` 依赖。
- 测试临时文件改用系统临时目录（只读环境也能跑）；测试 96 → 115 项。

## 测试

- 全量 **115 项通过**（不触网）。

## 安装与使用

1. 解压 zip 到任意目录
2. 双击 `campus-auth.exe`
3. 首次启动：弹出配置界面 + 托盘 + 创建桌面快捷方式
4. 填门户地址（或断网点「自动获取」）→ 自动探测类型 → 一键生成 → 开始自动登录
