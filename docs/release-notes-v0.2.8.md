# campus-auth v0.2.8

> 修复断网（未认证）时「自动获取」取不到门户地址的问题。

## 🐛 修复

### 「自动获取」门户地址

旧版只访问 `www.baidu.com` 一个目标，且没有 DNS 故障回退：

- 校园网 DNS 故障时域名解析直接失败 → 探测失败；
- 网关劫持写法不是简单 `location.href` 时（meta refresh、表单跳转等）也识别不到；
- 失败时只有一句「未获取到」，无法排查。

v0.2.8 起：

1. **多探测目标**：域名优先，失败后自动回退公网 IP 直连（`223.5.5.5`、`119.29.29.29` 等）——网关同样会劫持这些 IP 的 HTTP 流量，DNS 故障时也能取到认证页地址。
2. **支持更多劫持写法**：`Location` 头、`location.href` / `window.location` / `location.replace`、`meta http-equiv="refresh"`、登录表单 `action`、以及正文中出现的第一个 `eportal/portal` URL。
3. **非标准端口保留**：门户在 `8080` 等端口时填入 `host:port`，不再丢端口。
4. **失败也有信息**：弹窗会列出每个探测目标的尝试记录，并提示检查「是否已连校园网」「是否处于未认证状态」，便于快速定位问题。
5. **后台获取**：多目标探测在后台线程执行，按钮显示「获取中…」，界面不再卡死。

## 🧪 测试

- 新增 12 项测试：门户 URL 提取（Location/JS/meta/表单/eportal/非标端口/无特征）与多目标探测（DNS 故障回退、全部失败、已联网场景）。
- 测试总数 **123 → 135**，全部通过（不触网）。

## 安装与使用

1. 解压 zip 到任意目录
2. 双击 `campus-auth.exe`
3. 首次启动：弹出配置界面 + 托盘 + 创建桌面快捷方式
4. 连上校园网（未认证）→ 点「自动获取」→「一键生成配置」（自动校验类型）→「开始自动保护」
5. 勾选「开机自启」后，重启电脑自动以托盘运行

## 注意事项

- 无需安装 Python，独立运行
- 若杀毒软件提示，请添加信任
- 从旧版升级：解压覆盖 `_internal` 与 `campus-auth.exe`，**不要删除同目录下的 `portal.json`**
