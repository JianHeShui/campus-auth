# campus-auth v0.3.0

> 累积多轮改进的大版本：CAS 认证更稳、自动登录改为独立守护进程、托盘可见保护状态、门户地址自动获取更可靠，并完成日志脱敏与工程化清理。

## 🚀 亮点

- **CAS 认证更稳**：完整保留门户下发的多个 Cookie；上线步骤逐项校验，不再「假成功」
- **真正的后台保护**：自动登录由独立进程运行，关窗不中断；保护中再次开始会自动重启
- **托盘状态可见**：悬浮提示与右键菜单实时显示「保护中 / 未保护」
- **自动获取地址更可靠**：DNS 故障时回退公网 IP，支持多种网关跳转写法
- **一键生成自动校验类型**：探测结果与所选类型不一致时提醒，可一键切换
- **日志脱敏**：账号、密码、密钥、会话 token 均不落日志明文

## 🐛 认证稳健性

### CAS 多 Cookie 保留

门户一次响应可能下发多个 `Set-Cookie`（`SESSION`、`JSESSIONID` 等），旧版只保留第一个，导致后续 CAS 登录因会话不完整被拒。现在全流程使用 Cookie 罐，逐步累积并携带。

### CAS 上线判定修复

工作流上线步骤（取节点 → 服务选择 → 服务登录 → 上线确认）每一步都校验 HTTP 状态与业务 `code`；`userOnline` 校验 `data.online`。不再出现「日志显示已上线、实际未放行」。

### 联网探测更准

- 优先使用不依赖 DNS 的 NCSI 检测点做 IP + 内容校验，再做域名 TLS 探测；
- 校园网 DNS 故障时不再误判「未联网」；
- HTTPS 可达判定放宽为 2xx/3xx；业务 `code` 兼容字符串形式。

### 门户类型探测

- 多处特征请求并发执行，探测耗时明显缩短；
- CAS 判定改为校验响应正文确实是 JavaScript，SPA 门户「任意路径返回 200」不再误判；
- 自签名 HTTPS 门户自动用宽松模式重试。

### 自动获取门户地址

- 域名 + 公网 IP 多目标探测：DNS 故障时回退 IP 直连（网关同样劫持 HTTP），也能取到认证页地址；
- 支持 `Location` 重定向、JS 跳转、meta refresh、登录表单 action、eportal URL 等多种劫持写法；
- 非标准端口保留为 `host:port`；失败时列出探测记录与排查建议；
- 获取动作在后台执行，界面不再卡死。

## 📌 保护状态与托盘

- 托盘悬浮提示与右键菜单首行显示「保护中 / 未保护」，状态自动同步；
- 保护中再点「开始保护」（或配置界面「开始自动保护」）会先停止再启动，新配置立即生效；
- 菜单：状态 / 配置 / 开始（重新开始）保护 / 停止保护 / 退出；退出托盘会停止保护。

## 🔒 日志脱敏

- 认证日志不再记录账号明文、密码密文、AES 密钥、`execution`、`sessionId`、`ticket`、Cookie 值；
- 日志超过 2MB 自动轮转，避免长期运行无限增长。

## 🖥️ 配置界面

- 端口与高级字段（JSON）输入校验，错误明确提示；
- 关闭窗口自动保存失败时会提示；
- 窗口按屏幕可用区自适应（小屏不再超屏 / 按钮被裁）；
- 探测期间按钮显示「探测中…」，获取门户地址时显示「获取中…」；
- 清理未使用的死代码，界面与代码更易维护。

## 🪟 系统集成

- 修复 windowed 模式无控制台时的打印崩溃隐患。

## 下载

- **`campus-auth-v0.3.0.zip`**（推荐，目录版，约 17 MB）
- **`campus-auth-v0.3.0-单文件版.exe`**（便携单文件，免解压；首次启动稍慢）

## 安装与使用

1. 解压 zip 到任意目录（或直接使用单文件版）
2. 双击 `campus-auth.exe`
3. 首次启动：配置界面 + 托盘 + 桌面快捷方式
4. 连上校园网（未认证）→「自动获取」→「一键生成配置」（自动校验类型）→「开始自动保护」
5. 勾选「开机自启」后，重启电脑自动以托盘运行

## 注意事项

- 无需安装 Python，独立运行
- 若杀毒软件提示，请添加信任
- 从旧版升级：解压覆盖 `_internal` 与 `campus-auth.exe`，**不要删除同目录下的 `portal.json`**
- 旧日志可能含历史敏感内容，建议删除一次：`~/.campus-auth/auth-debug.log`
